# 使用说明

输入即搜索。首个词若是某个插件的关键词，查询就交给该插件；否则整段输入作为应用与命令查询。路由规则见[插件](plugins.md#路由)。

`Enter` 执行高亮行。空查询不显示任何行。

## 查询类型

下表列出内置关键词，插件还可以添加自己的关键词。

| 输入 | 操作 |
| --- | --- |
| `firefox` | 搜索已安装应用（名称、关键词、描述） |
| `f <query>` | 按文件名或路径搜索 |
| `d <query>` | 按路径搜索目录（支持多个词） |
| `r <query>` | 模糊搜索 `$PATH` 可执行文件并运行 |
| `?` | 显示关键词模式、默认功能、提示，以及各插件已记住的默认动作 |
| `lock` / `reboot` / `shutdown` | 系统命令 |
| `2 + 3` | 即时计算 |

KDE Plasma 下，`reboot`、`shutdown` 与 `logout` 先通过 D-Bus 请求会话管理器（`org.kde.Shutdown`）注销，调用失败时回退到 `systemctl`/`loginctl`。直接通过 systemd 停止 `plasmashell` 可能让关机卡住。

有些功能依赖可选组件。复制与粘贴需要 `wl-clipboard`；缺少时，对应关键词返回空结果。在 `plugins.toml` 注册的宿主也会以同样方式带来关键词。完整列表见[功能依赖](install.md#功能依赖)。

### 路径查询

含 `/` 或以 `~` 开头的查询是路径查询。路径存在时，启动器直接打开它，不再按名字搜索。`~` 与相对路径在 `$HOME` 下解析；绝对路径（如 `/etc/hosts`）按原样打开。

路径尚不存在时，启动器列出所输入目录中匹配最后一段的条目。查询以 `/` 结尾则列出整个目录。匹配忽略大小写，已输入的父目录名也一样。存在的精确路径仍按字面打开。

### 没有提供者命中时

普通查询没有任何提供者命中时，启动器按同样方式列出 `$HOME` 的第一层。

## 按键

| 按键 | 操作 |
| --- | --- |
| `Enter` | 打开选中结果 |
| `Shift+Enter` | 打开选中结果的动作面板 |
| `Alt+Enter` | 在动作面板中把高亮命令设为所属插件的默认动作，或再次按下取消 |
| `↑` / `↓` | 移动选择 |
| `PageUp` / `PageDown` | 按页移动 |
| `Tab` | 用结果补全最后一个词或路径组件 |
| `Home` / `End` | 光标移到查询开头/结尾 |
| `Ctrl+A` | 全选查询内容 |
| `Shift+←/→` | 扩展选区 |
| `Ctrl+C` / `Ctrl+X` | 将选区复制到剪贴板 |
| `Ctrl+V` | 粘贴 |
| `Delete` | 删除光标后的字符 |
| `Esc` | 退出（或关闭动作面板） |

## 动作面板

### 打开面板

`Shift+Enter` 为高亮行打开一个 Wox 风格的第二层命令面板，列出该类型结果可用的命令。

页脚右端、动作计数左侧显示当前操作的行或进入的分组名；名称过长会截断。页脚关闭时面板不显示标题。

面板先列行自身的命令（**打开**），再列插件为该类型补充的动作。文件行提供「在终端中打开」「在文件管理器中显示」「复制路径」，然后是一个**用其他应用打开**分组，包含系统提供的其他打开方式。应用行列出其 `[Desktop Action …]` 分组。外部宿主自带的动作排在最后。

圆点标出 `Enter` 会执行的那一条。没有默认动作时，它在**打开**上。没有任何命令的行不打开面板，页脚也不显示动作提示。

### 分组与层级

带 `›` 的分组不执行命令，而是展开第三层。在**用其他应用打开**上按 `Enter`，会按应用名列出各个打开方式；`Enter` 运行高亮的一个，`Esc` 退回该行的动作层。在这一层也能把某个打开方式设为默认，和其他条目一样。

面板打开时，`↑`/`↓` 与滚轮在其中移动。`Enter` 运行高亮命令或展开高亮分组。`Esc` 退回上一层；在最顶层则关闭面板。`Shift+Enter` 从任何一层直接关闭。输入任意字符会关闭面板并回到输入框。

### 默认动作

`Alt+Enter` 把高亮命令记为所属插件的默认动作。之后该插件的行按 `Enter` 会执行它，行原本的命令仍以**打开**留在面板里。默认动作带一个圆点，页脚显示 `Alt+Enter` 提示。在**打开**上按 `Alt+Enter`，或在已经是默认的动作上再按一次，即可取消， `Enter` 恢复为正常打开。插件自带的动作与外部宿主的动作都可以设为默认。

`Alt+Enter` 会重发查询，并让面板停在你改动的那一项上，默认圆点随之移动。

### 页脚与行标记

有默认动作生效时，行级页脚写出 `Enter` 实际执行的动作（`⏎ 在终端中打开`），而不是 `⏎ 打开`。行右端也会带上与面板相同的圆点，状态一眼可辨；过长的动作名会省略。`?` 会在每个插件后列出 `· Enter: <action id>`。

界面语言在 `config.toml` 中设置，见[配置](config.md#界面语言)。
