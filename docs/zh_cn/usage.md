# 使用说明

覆盖层只有一个输入框。输入即搜索；当某个插件拥有输入的第一个词作为前缀时，会路由到该插件，
否则整段输入作为应用/命令查询（见 [plugins.md](plugins.md)）。结果是若干行，`Enter` 作用于高亮行。

## 前缀

| 输入 | 操作 |
| --- | --- |
| `firefox` | 模糊搜索已安装应用 |
| `b <关键词>` | 搜索 Firefox 书签 |
| `h <关键词>` | 搜索 Firefox 历史 |
| `f <关键词>` | 按文件名或路径搜索 |
| `d <关键词>` | 按路径搜索目录（多词） |
| `r <关键词>` | 模糊搜索 `$PATH` 可执行文件并运行 |
| `w <关键词>` | 切换到匹配的打开窗口 |
| `c <关键词>` | 搜索剪贴板历史 |
| `s <关键词>` | 网页搜索建议（引擎在 `config.toml` 中设置） |
| `?` | 显示关键词模式、默认功能与提示 |
| `lock` / `reboot` / `shutdown` | 系统命令 |
| `2 + 3` | 即时计算 |
| *(留空)* | 展示高频使用项 |

查询含 `/` 或以 `~` 开头时视为**路径查询**：会直接 stat，存在即打开，即使超出深度 3 的
遍历范围。`~` 与相对路径在 `$HOME` 下解析；遍历不离开 `$HOME`，但绝对路径（如
`/etc/hosts`）会按原样打开。

## 按键

| 按键 | 操作 |
| --- | --- |
| `Enter` | 打开选中结果 |
| `Shift+Enter` | 打开选中结果的二级菜单 |
| `Alt+Enter` | 在二级菜单中把高亮命令设为所属插件的默认，或再次按下取消 |
| `↑` / `↓` | 移动选择 |
| `PageUp` / `PageDown` | 按页移动 |
| `Home` / `End` | 光标移到查询开头/结尾 |
| `Ctrl+A` | 全选查询内容 |
| `Shift+←/→` | 扩展选区 |
| `Ctrl+C` / `Ctrl+X` | 将选区复制到剪贴板 |
| `Ctrl+V` | 粘贴 |
| `Delete` | 删除光标后的字符 |
| `Esc` | 关闭（或关闭二级菜单） |

## 二级菜单

`Shift+Enter` 为高亮行打开一个 Wox 风格的第二层菜单，列出该类型结果可用的命令。菜单项由产出
该行的插件决定：文件行提供“在文件管理器中显示”，应用行列出其 `[Desktop Action …]`，书签或
搜索命中提供“复制链接”，外部主机也可以自带动作。每个可操作的行还会得到启动器级别的
**置顶** / **取消置顶**；只有空查询历史里、且确实被记入历史的行才会额外提供 **从历史中
移除**。没有任何命令可提供的行不打开菜单，页脚也不再显示其动作提示。

菜单打开时，`↑`/`↓`（以及滚轮）在其中移动，`Enter` 运行高亮命令，`Esc` 或 `Shift+Enter`
关闭；输入任意字符会关闭菜单并回到输入框。

`Alt+Enter` 把高亮命令记为所属插件的默认动作，之后该插件的行按 `Enter` 会执行它；行原本的
命令会以 **Open** 留在菜单里，不会丢。设为默认的动作带一个小圆点，页脚显示 `Alt+Enter` 提示；
再按一次即可取消。启动器级动作与外部主机自带动作没有稳定 id，不能设为默认。

## 置顶

**置顶**会把该行按当时那条完整查询（整段去除首尾空白的输入，含关键词）保存，之后再次搜索
同一条字符串时，它会排在结果最前。在 `firefox` 上置顶 Firefox，则只有搜 `firefox` 时领跑，
搜 `fire` 或只输入关键词不会触发；在 `b firefox` 上置顶，则只对 `b firefox` 生效。空查询是
独立的作用域，在那里置顶会领跑历史。新结果中的重复项会被去掉，因此置顶行只出现一次。
**取消置顶**将其移除；置顶数据存放在 `usage.db`。
