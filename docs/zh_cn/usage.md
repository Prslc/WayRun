# 使用说明

输入即搜索：当某个插件拥有输入的第一个词作为前缀时，会路由到该插件，否则整段输入作为
应用/命令查询（见 [plugins.md](plugins.md)）。`Enter` 作用于高亮行。

## 前缀

| 输入 | 操作 |
| --- | --- |
| `firefox` | 模糊搜索已安装应用 |
| `b <关键词>` | 搜索 Firefox 书签 |
| `h <关键词>` | 搜索 Firefox 历史 |
| `f <关键词>` | 按文件名或路径搜索 |
| `d <关键词>` | 按路径搜索目录（多词） |
| `r <关键词>` | 模糊搜索 `$PATH` 可执行文件并运行 |
| `w <关键词>` | 切换到匹配的打开窗口 |
| `c <关键词>` | 搜索剪贴板历史（cliphist） |
| `s <关键词>` | 网页搜索建议（引擎在 `config.toml` 中设置） |
| `?` | 显示关键词模式、默认功能、提示，以及各插件已记住的默认动作 |
| `lock` / `reboot` / `shutdown` | 系统命令 |
| `2 + 3` | 即时计算 |
| *(留空)* | 展示高频使用项 |

表中有几个前缀依赖可选组件：`w` 需要合成器后端，`b`/`h` 需要 Firefox，`c` 需要
cliphist，复制/粘贴需要 `wl-clipboard`。缺少组件时，对应关键词只会返回空结果。完整列表见
[README](README_CN.md#功能依赖)。

查询含 `/` 或以 `~` 开头时视为**路径查询**：路径存在就直接打开，不再按名字搜索。
`~` 与相对路径在 `$HOME` 下解析；绝对路径（如 `/etc/hosts`）按原样打开。

## 按键

| 按键 | 操作 |
| --- | --- |
| `Enter` | 打开选中结果 |
| `Shift+Enter` | 打开选中结果的二级菜单 |
| `Alt+Enter` | 在二级菜单中把高亮命令设为所属插件的默认，或再次按下取消 |
| `↑` / `↓` | 移动选择 |
| `PageUp` / `PageDown` | 按页移动 |
| `Home` / `End` | 光标移到查询开头/结尾 |
| `Ctrl+A` | 全选查询内容 |
| `Shift+←/→` | 扩展选区 |
| `Ctrl+C` / `Ctrl+X` | 将选区复制到剪贴板 |
| `Ctrl+V` | 粘贴 |
| `Delete` | 删除光标后的字符 |
| `Esc` | 关闭（或关闭二级菜单） |

## 二级菜单

`Shift+Enter` 为高亮行打开一个 Wox 风格的第二层菜单，列出该类型结果可用的命令。顺序是：
行自身的命令（**打开**）在最前，接着是插件为该类型补的动作——文件行提供“在终端中打开”
“在文件管理器中显示”“复制路径”，应用行列出其 `[Desktop Action …]`，书签或搜索命中提供
“复制链接”——然后是外部主机自带的动作，最后才是启动器级条目：**置顶** / **取消置顶**，
以及空查询历史来源的行才有的 **从历史中移除**。圆点标出 `Enter` 会执行的那一条，因此没有
默认动作时它在 **打开** 上。没有任何命令可提供的行不打开菜单，页脚也不再显示其动作提示。

菜单打开时，`↑`/`↓`（以及滚轮）在其中移动，`Enter` 运行高亮命令，`Esc` 或 `Shift+Enter`
关闭；输入任意字符会关闭菜单并回到输入框。**置顶**/**取消置顶** 与 `Alt+Enter` 都会重发查询并让
菜单留在原位——置顶项就地变成取消置顶，默认圆点也移到你按下的那一项。

`Alt+Enter` 把高亮命令记为所属插件的默认动作，之后该插件的行按 `Enter` 会执行它；行原本的
命令会以 **打开** 留在菜单里。设为默认的动作带一个小圆点，页脚显示 `Alt+Enter` 提示；在
**打开** 上按 `Alt+Enter`（或在已经是默认的动作上再按一次）即可取消，`Enter` 恢复为正常
打开。启动器级动作（置顶/取消置顶、从历史中移除）不能设为默认；插件自带动作与外部主机自带的
动作可以。

有默认动作生效时，行级页脚会把 `Enter` 实际要跑的动作写出来（`⏎ 在终端中打开`），而不是
`⏎ 打开`，同时行右端带上与菜单里相同的圆点，一屏行的状态一眼可见；过长的动作名会省略。
`?` 会在每个插件的说明后附上 `· Enter: <动作 id>`。

## 语言

界面跟随会话的语言环境，只在启动时读取一次：依次取 `$LC_ALL`、`$LC_MESSAGES`、`$LANG`，
再取 `$LANGUAGE` 的第一项。目前内置英文与简体中文；其他语言一律退回英文。

要让语言不随会话变化，用 `config.toml` 的 `[ui] locale` 固定即可；常驻服务尤其需要它——它的
unit 要么继承会话的语言环境，要么什么都没有。在 unit 里设 `Environment=LC_ALL=zh_CN.UTF-8`
同样有效。两种方式都只在启动时读取，改完需重启服务。

## 置顶

**置顶**会把该行按当时那条完整查询（整段去除首尾空白的输入，含关键词）保存，之后再次搜索
同一条字符串时，它会排在结果最前。在 `firefox` 上置顶 Firefox，则只有搜 `firefox` 时领跑，
搜 `fire` 或只输入关键词不会触发；在 `b firefox` 上置顶，则只对 `b firefox` 生效。空查询是
独立的作用域，在那里置顶会领跑历史。新结果中的重复项会被去掉，因此置顶行只出现一次。
**取消置顶**将其移除。
